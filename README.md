# Generative Art Workshop

This repository contains lesson folders for a generative-art workshop organized around **concepts** (not tools).

Open any lesson's `index.html` in a browser to run the sketch (no build tools required).

## Lesson structure
Each lesson folder follows the same layout:
- `index.html` — page shell, links `style.css` and `sketch.js`
- `sketch.js` — the p5.js code for that lesson, heavily commented, favoring clarity over one-liners
- `style.css` — minimal page styling
- `README.md` — objective, how to run, key concepts, and "try this" exercises for that lesson

Lessons also link a shared `../shared/error-logger.js`.
