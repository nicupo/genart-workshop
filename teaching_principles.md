# Teaching principles

Students are programmers. 

Don't spend time on JavaScript basics.

Always demonstrate ideas visually.

Each lesson should produce something beautiful within 5–10 minutes.

Every sketch should be extendable.

Prefer simple code over clever code.

Avoid large frameworks.

Keep p5.js sketches under ~200 lines where possible.

The workshop is about emergence, not making pretty pictures.

Optimize for teaching and experimentation, not software engineering.

Each lesson must run independently.
